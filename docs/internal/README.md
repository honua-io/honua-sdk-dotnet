# Internal contributor docs

These documents are written for contributors and cross-repo maintainers. They
cover backlog, contract harmonization, transport ownership, and release cadence
for the Honua server / SDK family.

Consumers of the published `Honua.Sdk.*` NuGet packages should read the
top-level [docs/](../) folder (quickstart, troubleshooting, authentication,
capability guides, release process) instead.
